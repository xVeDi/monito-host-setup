# 📦 Установка Debian + Monito на TV Box (Tanix W2)

Все необходимые **программы, образы и прошивки** находятся здесь:  
👉 https://disk.yandex.ru/d/2KmTXsBYZu1VWA

---

## ⚠️ Требования

- **2 USB-флешки**
  - размер **не менее 4 ГБ**
  - **не более 32 ГБ** (64 ГБ может не определиться)
- ПК с Windows (для подготовки флешек)
- USB-мышь (понадобится для установки логотипа)
- **Зубочистка** (для кнопки Reset)

---

## 🔧 Подготовка флешек

### 🔹 Флешка №1 — Debian

1. Записать образ  
   **`Devmfc_Debian-Bookworm_6.12.17-meson64_Minimal-25.02.28.img`**  
   с помощью **Win32DiskImager**.

   ⚠️ **Важно**  
   Если Win32DiskImager не запускается — **отключите Google Drive**, эти программы несовместимы.

2. После записи открыть файл `boot.config` на флешке.
3. Раскомментировать строку с моделью приставки (убрать `#`):
```

box=tanixw2

```
4. Сохранить файл.

---

### 🔹 Флешка №2 — Logo / TWRP

1. Отформатировать флешку в **FAT32**.
2. Распаковать архив **TWRP**.
3. Скопировать в корень флешки:
- `aml_autoscript`
- `twrp.img`
4. Туда же скопировать файл:
- `monito-logo.img`

---

## 🐧 Установка Debian

### 1️⃣ Загрузка с первой флешки

1. Отключить питание приставки.
2. Вставить флешку **в USB2**  
(порт между USB3 (синий) и слотом SD-карты).
3. Зажать кнопку **Reset**  
(расположена внутри AV-разъёма) **зубочисткой**.
4. Не отпуская кнопку, включить питание.
5. Дождаться загрузки Debian с флешки.

---

### 2️⃣ Установка Debian во внутреннюю память (eMMC)

1. Подключиться к приставке по **SSH**.  
IP-адрес будет показан на экране.

**Креды по умолчанию:**
```

root / tvbox

````

2. Выполнить:
   ```bash
   ./aml-multiboot-setup.sh
   ````

   → на все вопросы отвечать **y**

3. Затем:

   ```bash
   ./aml-install-to-emmc.sh
   ```

   → на все вопросы отвечать **y**

⏱ Время установки ~3 минуты
⚠️ **ВНИМАНИЕ:** полностью стирает внутреннюю память приставки.

---

### 3️⃣ Загрузка Debian из eMMC

1. Извлечь флешку.
2. Перезагрузить приставку — должен стартовать Debian.
3. Подключиться по SSH.

   **Креды по умолчанию:**

   ```
   root / tvbox
   ```

---

## ⚙️ Установка Monito-скриптов

Выполнить команду:

```bash
apt-get update && apt-get install -y wget curl \
&& bash <(curl -fsSL https://raw.githubusercontent.com/xVeDi/monito-host-setup/main/install.sh)
```

После выполнения:

* hostname станет `monito-box`
* **креды изменятся на**

```
root / monito
```

---

## 🚀 Установка Monito

Запустить:

```bash
./monito-install.sh
```

---

## 🖼 Установка логотипа Monito

⚠️ **Понадобится USB-мышь** (подключить в USB3).

### 1️⃣ Загрузка TWRP со второй флешки

1. Отключить питание.
2. Вставить вторую флешку **в USB2**.
3. Зажать кнопку **Reset зубочисткой**.
4. Включить питание, не отпуская кнопку.
5. Дождаться загрузки **TWRP**.

---

### 2️⃣ Прошивка логотипа

В TWRP:

```
Home
 → Install
 → Select Storage
   → USB OTG (выбрать флешку, НЕ Internal Storage)
 → Install Image
 → monito-logo.img
 → Select Partition to Flash Image
   → Logo
 → Swipe to confirm Flash
 → Reboot
```
